School Tycoon runtime update — experimental, not a verified playable port

Exit the old session. Extract into /userdata/roms/ports/ and replace included
files. Launch School Tycoon normally. Do not delete your game files or prefix.

The installer handles stale runtime links and retains verified Wine downloads.
Existing installed Wine is reused. Actual game assets and saves are excluded
from this update. Missing-prefix links are preserved under dated backup names.

The prefix helper restores missing builtin modules for both Windows architectures
from the installed Wine runtime, preserving existing nonempty modules and files.
For an existing prefix with system.reg and user.reg, it checks 32-bit Windows
execution without repeating wineboot -u/Active Setup, which aborted in advpack.
The command must print its exact marker and exit zero before the game can start.
Existing-prefix verification allows up to two minutes, plus service cleanup.
A genuinely new prefix still allows up to five minutes for initial setup first.

Progress/failure logs:
  logs/prefix-setup.txt
  logs/prefix-32.txt
  logs/prefix-32.stdout.txt
On command failure, source/prefix core-module hashes are saved in:
  logs/prefix-modules.txt
Verified prefixes skip repeated repair. A failed verification leaves the prefix
intact and stops before launching the game. No separate test commands are needed.

The EGL helper loads native EGL/SDL directly and primes EGL before Wine address
mappings. This has not yet established successful game rendering on the handheld.
CPU verification does not prove sound, COM services, shaders, saves or performance.

This revision disables Wine's bundled Internet Explorer executable during setup
and game-session service startup. The fresh-prefix trace showed iexplore.exe
aborting while loading advpack.dll with access-violation status c0000005.
The RegInstallA export exists; no DLL stub or fake implementation is installed.
Wine's normal override mechanism suppresses the browser registration helper.
Both missing-module restoration and the 32-bit execution gate remain enabled.
Keep your currently repaired prefix; another reset is not required for this change.
